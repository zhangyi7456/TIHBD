# TIHBD 资产周期数据字典 v1

## 时间与历史截面

- 业务周使用 ISO Week。
- 每周快照的统一可用时点为观察周后的周一 08:00（Asia/Shanghai）。
- 数据进入历史快照的硬条件是 `providerAvailableAt <= snapshotAsOf`，不是只比较行情日期。
- 当前公开接口无法恢复数据供应商过去每一次真实发布时间。本版按市场收盘与保守缓冲时间重建 `providerAvailableAt`，因此页面标记为“重建历史截面”，不是逐时点原始 vintage（历史版本）。
- 股票指数当前均为价格指数，不含股息，不能解释为总回报。

## 周频聚合

每个业务周取当周最后一个有效交易日的收盘值，并保留真实 `sourceObservationDate`。不同市场不强求共同交易日。

周涨跌和动量：

```text
weeklyReturn = P(t) / P(t-1) - 1
momentum(k) = P(t) / P(t-k) - 1, k ∈ {4, 13, 26}
```

历史分位的生产定义应为“当前26周动量相对此前260个已完成周的经验分位”，比较样本不包含当前周。有效历史少于104周时返回 `INSUFFICIENT_HISTORY`，不得输出伪精确分位。

## 数据状态

- `OK`：当周存在有效值。
- `MISSING`：预期当周有数据，但无可用观测。
- `STALE`：使用此前观测，仍在允许宽限期。
- `EXPIRED`：超过该序列 `maxAgeDays`；保留最后值但禁止产生新趋势信号。
- `SOURCE_ERROR`：抓取或解析失败，不能等同市场休市。
- `INSUFFICIENT_HISTORY`：当前值存在，但派生窗口不足。

真实源失败时不得静默切换为 DEMO（演示）。允许显示上次真实值并标记过期，或切换到经过批准且记录映射版本的 PROXY（代理）。

## 暂未真实化的资产
